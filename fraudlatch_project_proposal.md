# FraudLatch Project Proposal

This file is a compatibility entry point for the project proposal. The canonical, dated base plan is maintained at [`milestones/00-proposal.md`](milestones/00-proposal.md).

Use the canonical proposal as the starting point for architecture and scope. Use [`milestones/0.md`](milestones/0.md) to follow implementation order and current status, and use the numbered child milestones for issue-sized work and acceptance criteria.

Do not maintain a second architecture plan in this file. Any proposal change must be made in `milestones/00-proposal.md` and recorded in the roadmap or an ADR when it changes an accepted decision.
