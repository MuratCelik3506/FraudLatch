# Milestone 9.2 — PostgreSQL and Redis Resources

Status: Complete
Parent: 9
Depends on: 9.1
Owner: Repository maintainer

## Goal

Run PostgreSQL and Redis locally with persistent volumes, health checks, and safe connection configuration.

## Why this matters

These services are the durable and operational foundations of the application. Terraform-managed lifecycle lets contributors reproduce the same dependencies and demonstrate drift/recovery behavior.

## Scope

- PostgreSQL container and volume
- Redis container and volume/configuration
- Health checks
- Local-only port bindings
- Environment-based credentials
- Resource dependencies

## Out of scope

- Application containers
- Production HA
- AWS RDS/ElastiCache

## Expected changes

Add `postgres.tf`, `redis.tf`, variables, connection outputs, and local service documentation.

## Implementation checklist

- [x] Create PostgreSQL container on the shared network.
- [x] Mount a persistent PostgreSQL volume.
- [x] Create Redis container, mount its named volume, and define the local persistence mode.
- [x] Bind ports only for local host access.
- [x] Pass credentials from ignored tfvars/environment inputs.
- [x] Add dependency references to network and volumes.
- [x] Verify restart preserves PostgreSQL data.

## Interfaces and contracts

Local defaults match `.env.example`: PostgreSQL database/user and Redis URL are reachable from host and container network contexts as documented.

## Validation

Connect with `psql` and `redis-cli`, restart containers, inspect Terraform state, and run `terraform destroy`.

## Acceptance criteria

- [ ] Both services become healthy after apply.
- [ ] Volumes persist data across recreation.
- [ ] Credentials are not present in tracked files or outputs.
- [ ] Local API/worker can connect using documented URLs.

## Failure and edge cases

Port conflicts, failed health checks, invalid credentials, and volume mount errors must stop the apply or be visible as unhealthy.

## Definition of done

PostgreSQL and Redis are reliable local Terraform resources ready for application and test use.

## Follow-up

Provision Prometheus and Grafana in 9.3.
