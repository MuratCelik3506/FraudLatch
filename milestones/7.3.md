# Milestone 7.3 — Transaction Replayer

Status: Complete
Parent: 7
Depends on: 2.2, 7.2
Owner: Repository maintainer

## Goal

Replay canonical transactions through the API at a controlled rate while preserving deterministic IDs and event times.

## Why this matters

The replayer turns static data into an event source for integration testing, operational demos, and future load testing.

## Scope

- Parquet streaming
- `--rate`, `--limit`, and `--seed`
- `--fraud-only`
- `--start-step` and `--end-step`
- HTTP retry policy
- Progress and failure reporting

## Out of scope

- Sending fraud labels to the API
- High-scale load testing tools
- Persistent replay scheduler

## Expected changes

Add `apps/replayer` entrypoint, HTTP client, CLI parser, and replay tests.

## Implementation checklist

- [x] Stream rows instead of loading the entire dataset.
- [x] Enforce positive rate and non-negative limit.
- [x] Filter fraud-only and step ranges deterministically.
- [x] Retry network/5xx failures with the same transaction ID.
- [x] Report permanent 4xx failures with row and transaction ID.
- [x] Exit non-zero when replay is incomplete.

## Interfaces and contracts

Replay wall-clock rate controls request pacing only. Canonical `event_time` remains derived from `source_step`.

## Validation

Replay a small fixture, test filters, network retry, 4xx handling, limit handling, and repeated same-seed output.

## Acceptance criteria

- [ ] At least 1,000 transactions can be replayed.
- [ ] Same seed produces the same transaction IDs.
- [ ] Retries do not create new IDs.
- [ ] Partial failure is reported and not mistaken for success.

## Failure and edge cases

Interrupted replay may be safely restarted because ingestion is idempotent. A malformed row must identify the row and stop or be explicitly skipped according to a documented CLI option.

## Definition of done

The replayer can feed the local API predictably and supports offline evaluation correlation by transaction ID.

## Follow-up

Use replay in 10.3 and expose throughput metrics in 8.1.
