# Milestone 1.1 — Repository Conventions and Project Language

Status: Complete
Parent: 1
Depends on: —
Owner: Repository maintainer

## Goal

Make English the explicit language of all new repository artifacts and define the conventions contributors must follow.

## Why this matters

FraudLatch is a portfolio and engineering-learning project. A single language makes design decisions reviewable by an international audience and avoids inconsistent operational terminology.

## Scope

- English source, documentation, issues, pull requests, and CI descriptions
- Naming and directory conventions
- Secret and licensed-data handling
- ADR expectations
- Commit and pull request expectations

## Out of scope

- Translating the full historical proposal; that is Milestone 1.2.
- Enforcing conventions with custom automation.

## Expected changes

The existing language ADR, README conventions, security policy, `.gitignore`, and pull request template are the source of truth.

## Implementation checklist

- [x] Add an English-only language ADR.
- [x] Document secret and dataset exclusions.
- [x] Add a pull request checklist.
- [x] Add a security reporting policy.

## Interfaces and contracts

New repository artifacts must be written in English. Raw BankSim data, `.env`, Terraform state, and secret-bearing variable files must not be committed.

## Validation

```bash
rg -n -i "password|secret|access_key" --hidden -g '!.git/**'
git diff --check
```

Review matches manually to distinguish documentation examples from leaked values.

## Acceptance criteria

- [x] New project artifacts use English.
- [x] Secret, Terraform state, and raw dataset exclusions are documented.
- [x] Contributors can find future architecture decisions.

## Failure and edge cases

Documentation examples may contain placeholder secret names but never real values. Existing historical content is not silently rewritten by unrelated implementation work.

## Definition of done

The language ADR and repository policies are present, linked, and followed by all new milestone documents.

## Follow-up

Use the conventions while completing 1.2 and all later milestones.
