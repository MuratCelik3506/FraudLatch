# Milestone 11.1 — CI Quality Gate

Status: Complete
Parent: 11
Depends on: 1.3, 10.1, 10.2
Owner: Repository maintainer

## Goal

Run the same quality contract in GitHub Actions that developers run locally.

## Why this matters

Consistent CI prevents environment-specific regressions and gives reviewers a trustworthy merge signal.

## Scope

- Ruff formatting and linting
- Mypy
- Pytest
- Testcontainers integration job
- Terraform formatting/validation matrix
- Conditional Docker builds
- Concurrency cancellation

## Out of scope

- AWS credentials
- Automatic deployment
- Production image publishing

## Expected changes

Update `.github/workflows/ci.yml` and align dependency versions with `pyproject.toml`.

## Implementation checklist

- [x] Install project and development dependencies on Python 3.12.
- [x] Run format check, lint, type check, and unit tests.
- [x] Run integration tests with Docker services.
- [x] Validate every Terraform root with backend disabled.
- [x] Build API/worker images only when Dockerfiles exist.
- [x] Build dispatcher images when the dispatcher Dockerfile exists (see 9.4).
- [x] Cancel stale runs for the same branch.
- [x] Publish coverage as a diagnostic artifact or summary.

## Interfaces and contracts

CI commands mirror `make quality`. Terraform validation must not access remote state or AWS credentials.

## Validation

Use a deliberate failing branch for each job and verify the corresponding check fails and recovers after the fix.

## Acceptance criteria

- [ ] Clean PR passes all required jobs.
- [ ] Lint/type/test failures block the PR.
- [ ] Terraform validation is isolated per root.
- [ ] Docker build failures are reported when images exist.
- [ ] No AWS secret is available to ordinary PR jobs.

## Failure and edge cases

Fork PRs, absent optional roots, unavailable Docker, dependency installation failure, and test timeouts must be explicit in job output.

## Definition of done

CI is a deterministic, credential-free quality gate for the local platform.

## Follow-up

Configure branch rulesets with stable check names after this milestone.
