# Milestone 12 — Deferred AWS Architecture

Status: Deferred
Parent: —
Depends on: 2–11
Owner: Repository maintainer

## Goal

Move the proven local application contract to AWS without changing domain behavior or weakening reliability guarantees.

## Why this matters

AWS is the cloud demonstration target, but implementing it before the local vertical slice is stable would mix infrastructure debugging with application correctness. The adapter boundaries keep the cloud phase incremental.

## Scope

- SQS queue adapter
- S3 remote state and lockfile
- VPC, IAM, and Secrets Manager
- ECS/Fargate, RDS, ElastiCache, ECR, ALB, and CloudWatch

## Out of scope

- Kubernetes/EKS
- Multi-region deployment
- Automatic production deployment
- Blue/green deployment before basic smoke tests

## Expected changes

Child milestones 12.1–12.4 define the AWS adapter and Terraform environment.

## Implementation checklist

- [ ] Complete local Milestones 2–11 first.
- [ ] Complete 12.1.
- [ ] Complete 12.2.
- [ ] Complete 12.3.
- [ ] Complete 12.4.

## Interfaces and contracts

AWS implementations must satisfy the same queue, event, database, health, metrics, and idempotency contracts proven locally.

## Validation

AWS work begins only when account access, budget controls, and OIDC role setup are available.

## Acceptance criteria

- [ ] AWS plan is reviewable without apply.
- [ ] Apply is manual and environment-protected.
- [ ] A complete demo can be destroyed after use.
- [ ] No local domain code is forked for AWS.

## Failure and edge cases

Unexpected cost, IAM denial, private-network reachability, task health failure, state lock contention, and partial deployment must be documented in the runbook.

## Definition of done

AWS is a reproducible, tagged, least-privilege extension of the local platform.

## Follow-up

Begin with SQS adapter contract tests in 12.1 after AWS access is available.
