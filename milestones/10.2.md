# Milestone 10.2 — Testcontainers Integration Tests

Status: Not started
Parent: 10
Depends on: 2–6
Owner: Repository maintainer

## Goal

Run isolated integration tests against disposable PostgreSQL and Redis containers.

## Why this matters

The most important behavior crosses process and service boundaries. Testcontainers keeps these tests reproducible in local development and CI without relying on a developer’s long-lived state.

## Scope

- PostgreSQL container lifecycle
- Redis container lifecycle
- Alembic migration tests
- API/database integration
- Outbox/dispatcher integration
- Worker/queue integration

## Out of scope

- AWS services
- Long-running performance tests
- Shared developer databases

## Expected changes

Add integration fixtures, Testcontainers dependencies, database cleanup strategy, and integration test markers.

## Implementation checklist

- [ ] Start isolated PostgreSQL per session or test scope.
- [ ] Start isolated Redis with unique namespace.
- [ ] Run Alembic migrations before tests.
- [ ] Test transaction/outbox persistence.
- [ ] Test Redis Stream publish/receive/ack.
- [ ] Test worker result persistence.
- [ ] Ensure teardown removes containers and data.

## Interfaces and contracts

Integration tests exercise concrete adapters but use the same public ports and migrations as application processes.

## Validation

```bash
pytest -m integration
```

Docker must be available; absence must produce a clear setup error.

## Acceptance criteria

- [ ] Tests do not depend on pre-existing local data.
- [ ] Migrations run on an empty database.
- [ ] Outbox, Redis Streams, and worker integration pass together.
- [ ] Test teardown is reliable after failures.

## Failure and edge cases

Container startup timeout, port allocation failure, migration failure, and Redis restart must fail the test suite with actionable diagnostics.

## Definition of done

Database and queue integrations are tested in disposable, reproducible environments.

## Follow-up

Add crash/retry and full replay tests in 10.3.
