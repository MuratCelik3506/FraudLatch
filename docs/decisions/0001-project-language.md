# ADR 0001: English as the project language

## Decision

All repository artifacts will be written in English: source code, documentation, comments, configuration descriptions, issue templates, pull requests, and CI output intended for maintainers.

## Rationale

FraudLatch is a portfolio and production-engineering learning project. A single language keeps the repository easier to review and makes its design decisions accessible to an international audience.

The existing proposal is the original planning document. New and modified content follows this decision; the proposal can be translated as a separate documentation task without changing its technical scope.
